Cài đặt Aether HE Lighting thành App trên Máy Tính
Cách 1: Dùng gói App Desktop (.zip) chạy 1 chạm (Khuyên dùng trên Windows) Giải nén file Aether_HE_Lighting_Desktop_App.zip và nhấp đúp vào Chay_App_Win60HE.bat (hoặc app_desktop.py). Script sẽ mở cửa sổ App riêng biệt (không thanh địa chỉ) và lưu quyền kết nối USB vĩnh viễn.
Cách 2: Mở trực tiếp cửa sổ App độc lập bằng lệnh Edge / Chrome Bạn có thể tạo Shortcut trên Desktop với đường dẫn dưới đây để mở thẳng thành cửa sổ App: msedge.exe --app="http://127.0.0.1:8765/aula.html"
Cách 3: Cài thành PWA từ menu Chrome / Edge Khi mở qua localhost, nhấn biểu tượng Cài đặt (Install) trên thanh địa chỉ hoặc vào menu ⋮ → Ứng dụng (Apps) → Cài đặt trang này dưới dạng ứng dụng để ghim thẳng ra Desktop & Start Menu.
